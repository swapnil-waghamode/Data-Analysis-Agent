# 📊 Data Analysis Agent

A Streamlit app that lets you upload any CSV file and ask questions about it in plain English. Under the hood, a LangChain agent powered by a Groq-hosted LLM (`openai/gpt-oss-20b` by default) uses pandas tools to inspect, filter, and analyze your data.

## Features

- Upload any CSV and preview the first rows instantly
- Chat interface for asking questions about your data
- Agent with three tools:
  - `get_data_info` – shape, column names, data types, and first 5 rows
  - `filter_tool` – filter rows using a pandas `query` condition
  - `analyze_data` – run pandas expressions for stats and aggregations
- Conversation memory within a session (via LangGraph `InMemorySaver`)
- Fast inference through Groq

## Prerequisites

- Python 3.10 or higher
- A free Groq API key from [console.groq.com](https://console.groq.com)

## Setup

1. **Clone the repository**

   ```bash
   git clone <your-repo-url>
   cd "DATA ANALYSIS AGENT"
   ```

2. **Create and activate a virtual environment**

   ```bash
   python -m venv venv

   # Windows
   venv\Scripts\activate

   # macOS / Linux
   source venv/bin/activate
   ```

3. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

   Dependencies: `streamlit`, `langchain`, `langchain-groq`, `langgraph`, `pandas`, `python-dotenv`.

4. **Configure environment variables**

   Copy the example file and fill in your values:

   ```bash
   # Windows
   copy .env.example .env

   # macOS / Linux
   cp .env.example .env
   ```

   Then edit `.env`:

   ```env
   GROQ_API_KEY="your_groq_api_key_here"
   MODEL="openai/gpt-oss-20b"
   PROVIDER="groq"
   ```

   | Variable | Description |
   |---|---|
   | `GROQ_API_KEY` | Your Groq API key (required) |
   | `MODEL` | Groq model name. Must support tool calling. Default: `openai/gpt-oss-20b` |
   | `PROVIDER` | LLM provider name. Currently informational only (the app uses Groq) |

## Run the App

```bash
streamlit run app.py
```

Streamlit will open the app in your browser at `http://localhost:8501`.

## Usage

1. Upload a CSV file using the file picker.
2. Check the preview and row count to confirm it loaded.
3. Ask questions in the chat box, for example:
   - "What columns does this dataset have?"
   - "Show me all rows where Age > 30 and Department is Engineering"
   - "What is the average salary by department?"
   - "How many unique cities are there, and which is most common?"

## How It Works

```
User question
     │
     ▼
Streamlit chat input ──► LangChain agent (Groq LLM)
                              │
              ┌───────────────┼────────────────┐
              ▼               ▼                ▼
       get_data_info     filter_tool      analyze_data
              └───────────────┼────────────────┘
                              ▼
                      pandas DataFrame
                              │
                              ▼
                   Answer shown in chat
```

The uploaded CSV is stored in a module-level DataFrame that the tools read from. The agent decides which tool to call, runs it, and writes the final answer.

## Security Notes

- The `analyze_data` tool uses Python's `eval()` to run pandas expressions generated by the LLM. This is fine for local, personal use, but **do not deploy this publicly as-is**: a malicious prompt or file could lead to arbitrary code execution. For production, replace `eval` with a restricted expression parser or a sandbox.
- Never commit your `.env` file. It is already listed in `.gitignore`, along with `venv/`. If you accidentally committed it earlier, run `git rm --cached .env` and rotate your API key.
- `*.csv` is also ignored by default so your data files don't get committed. Remove that line from `.gitignore` if you want to track a sample CSV.

## Known Limitations

- Conversation memory uses a fixed `thread_id` (`"1"`), so all browser sessions of a running server share the same agent memory.
- The DataFrame is a global variable, so concurrent users would overwrite each other's data.
- Very large CSVs may exceed the model's context window when `filter_tool` returns many rows.

## Troubleshooting

| Problem | Fix |
|---|---|
| `GROQ_API_KEY` not found | Make sure `.env` exists in the project root and contains the key |
| Model not found / invalid | Check the `MODEL` value against Groq's current model list |
| `ImportError` for `create_agent` | Upgrade LangChain: `pip install -U langchain langgraph langchain-groq` |
| `ModuleNotFoundError: dotenv` | Install `python-dotenv` (not `dotenv`): `pip install python-dotenv` |
| "No CSV loaded." reply | Upload a CSV before asking questions |
